<h2> Инструкция по сборке apk-файла </h2>
<h4>Через командную строку:</h4>
1. Откройте терминал в папке проекта (или перейдите в нее через cd)  

2. Выполните команду для сборки:  
bash  
(Linux/Ubuntu)./gradlew assembleRelease  
(Windows) .\gradlew.bat assembleRelease  

Готовый APK будет в: app/build/outputs/apk/release/app-release.apk  
<h4> Установка APK на телефон:</h4>

Скопируйте APK файл на телефон (через USB или облачное хранилище)

На телефоне откройте файловый менеджер и найдите APK

Нажмите на него → Установить

Если появится предупреждение - разрешите установку из неизвестных источников

После установки приложение появится в списке приложений

<h4> Удаление приложения с телефона:</h4>
Стандартный способ:

Настройки → Приложения → Найдите ваше приложение → Удалить
